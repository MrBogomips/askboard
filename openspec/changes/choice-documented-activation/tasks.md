# Tasks

Each task writes its tests first and sees them fail for the right reason before it implements (the repository's TDD rule). "The check" means `GITHUB_TOKEN=$(gh auth token) bun run check`. "Coverage" means at least 80% of lines and functions for every source file the task changes, read from `bun test --coverage`'s per-file table. "Browser files" means the named files run with `bun packages/view/test/browser/run.ts --engines chromium,webkit` after `bun run build`, under the browser lock; `-- -t <pattern>` narrows a run (a file path after `--` does not).

Order: group 0, then group 1 (1.1 first; 1.2 and 1.3 in either order, not in parallel, since both re-record chunk sizes; 1.4 after both; 1.5 any time after 1.3; 1.6 last), then group 2. No group runs in parallel with another.
