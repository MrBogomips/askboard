# Tasks

Each task writes its tests first and sees them fail for the right reason before it implements (the repository's TDD rule). "The check" means `GITHUB_TOKEN=$(gh auth token) bun run check`. Browser scenarios run in Chromium and WebKit only at the end of a task group, after the check passes, under the shared browser lock. Groups 2 to 4 are independent after group 1 and may run in parallel worktrees; group 5 comes last.
