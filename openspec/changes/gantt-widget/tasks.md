# Tasks

Each task writes its tests first and sees them fail for the right reason before it implements (the repository's TDD rule). "The check" means `GITHUB_TOKEN=$(gh auth token) bun run check` (coverage threshold 80%); "the browser suite" means `bun packages/view/test/browser/run.ts --engines chromium,firefox,webkit` (an option goes before `--`, as in `-- -t <name>`). After each task: `openspec validate --all --strict --no-interactive`, `bun run format` with `git status` showing only the task's files, the check, and the browser suite when the task touches `packages/view`, `packages/widgets` or `tools/build/`; then tick the box with a `  - Note:` (what was built, the choices made, the evidence) and commit in conventional form, with no AI attribution of any kind. Commit hashes appear only in task text and notes, never in code.

## Scope and order

- **May change:** new files under `packages/contract/src/widgets/gantt/`, `packages/contract/src/fixtures/` and `packages/contract/test/`; one appended export block in each of `packages/contract/src/index.ts`, `validate.ts` and `fixtures/index.ts`; `packages/compute/src/` and `packages/compute/test/`; `packages/molecules/` (its `package.json` gains `@askboard/contract` in task 7.5 only); `packages/widgets/src/gantt/` and `src/graph/`; in `packages/view/src/`, the port's `board` and `onDerived`, the view protocol's `derived` and the question card's handling of it (design decision 10); `packages/view/test/browser/gantt.browser.ts` and its fixtures; `tools/build/shared-modules.ts` and its tests; `packages/view/chunk-sizes.json`; what tasks 1.1 and 1.2 bring in.
- **Never changes:** E1's schema files, `sets.ts` (`SCHEMA_SETS`, `SCHEMA_IDS`), `createAjv`, constants and existing fixtures; the `tree-widget` seams' behaviour and the Tree's files, `element-diff.ts` with its keyed shape, `validator.ts`, `shared/ids.ts`, `shared/number.ts` and the widget host included (a seam that does not fit is reported, never copied or patched here, design decision 1); every other `package.json` and `tsconfig*.json`; `packages/core` and `server`; `docs/`, except the AD-13 bullet task 8.1 applies from `spine-update-draft.md`; `openspec/changes/e1-walking-skeleton/` and `openspec/changes/tree-widget/`; `.claude/commands/opsx/` and `.claude/skills/openspec-*`; any other worktree.
