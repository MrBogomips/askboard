# Tasks

Each task writes its tests first and sees them fail for the right reason before it implements (the repository's TDD rule). "The check" means `GITHUB_TOKEN=$(gh auth token) bun run check` (it includes `check:skills`). "Coverage" means at least 80% of lines and functions for every file the task adds or changes, read from `bun test --coverage`'s per-file table. "Browser files" means the named files run with `bun packages/view/test/browser/run.ts --engines chromium,webkit` and the target the task names, under the browser lock. Every task that touches answers includes a test that the failing case appends nothing and publishes nothing (NFR-10, AD-10). Every string a component shows goes through the view's tables in en-US and it-IT (askboard-implementation, i18n), with the texts of `ux-update-draft.md`. After each task: `openspec validate --all --strict --no-interactive`, `bun run format` with `git status` showing only the task's files, the check; then tick the box with a note of about five lines (what was built, test counts, deviations) and commit in conventional form with no attribution, one commit per task. Contract versions follow askboard-contract-versioning (labels until task 7.2); appended export blocks and the chunk budget follow askboard-implementation.

Order: group 0 first, then group 1 (`contract`, at high effort). Then groups 2 (`core`, at high effort), 3 (`tools/build` and the widgets' shared code) and 4 (widget models) in parallel: they touch different packages and meet only through group 1's exports. Within them, task 4.1 follows task 3.1 (KaTeX installed) and task 4.3 follows task 3.2 (the shared time code). Task 0.4 (the PRD update, added on 2026-11-07) runs before task 3.4. Tasks 3.4 (the fonts' and outlines' licence), 3.5 and 3.6 (group 3's review fixes) follow task 3.3, in that order, and run before task 5.1; task 3.7 re-reviews them with task 0.4. Tasks 4.5 and 4.6 (group 4's review fixes, added on 2026-11-07) follow task 4.4 and run before task 5.1; task 4.7 re-reviews them. The 4.7 re-review's fixes (added on 2026-11-07) run before task 5.1: tasks 4.8 to 4.11 in order (the internal names, the depth count, the measurement, the limit), and task 3.9 (the CSS parser) after task 3.8, beside them, since it touches only `tools/build`; task 4.12 re-reviews all five. The 4.12 re-review's fixes (added on 2026-11-07) run before task 5.1: tasks 4.13 to 4.16 in order (the scan's infix and raw-token fixes, KaTeX's output measured, the re-measurement, the output bound), and beside them task 4.17 (the render queue, a file of its own) and task 4.18 (X-4, `tools/build` only); task 4.19 re-reviews all six.
