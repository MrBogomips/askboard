# Tasks

Each task writes its tests first and sees them fail for the right reason before it implements (the repository's TDD rule). "The check" means `GITHUB_TOKEN=$(gh auth token) bun run check`. "Coverage" means at least 80% of lines and functions for every source file the task changes, read from `bun test --coverage`'s per-file table. "Browser files" means the named files run with `bun packages/view/test/browser/run.ts --engines chromium,webkit,firefox --target session-process` after `bun run build`, under the browser lock; `-- -t <pattern>` narrows a run.

Order: group 0, then group 1, then groups 2 and 3 in either order (they touch different packages and share only group 1's type; they run one after the other in this worktree), then group 4. Inside a group, tasks run in their order.
