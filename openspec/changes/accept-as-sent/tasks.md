# Tasks

Each task names its tests first and sees them fail for the right reason before it implements. "The check" is `bun run check:agent`. Groups run in order, 0 to 9 (group 9 folds the pre-PR review, design.md decision 11): each reads the types or behaviour of the one before. Inside group 4, tasks 4.1 and 4.2 may run beside each other. Groups 7.1 to 7.4 may run beside group 6. A new browser file runs in Chromium only (`--engines chromium`); no local full or multi-engine e2e run.

**Pre-merge train.** This change alters a card's rendering, so before merge the coordinator dispatches `gh workflow run e2e.yml --ref worktree-feature-accept-as-sent -f cadence=nightly` and triages a red train against the last train on `main` (AGENTS.md, CI; askboard-delivery).
