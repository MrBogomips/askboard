# Tasks

Each task writes its tests first and sees them fail for the right reason before it implements (the repository's TDD rule); a test that passes at once is recorded in the note with the code that already gives the behaviour. "The check" means `GITHUB_TOKEN=$(gh auth token) bun run check` (coverage threshold 80% per file); "the browser suite" means `bun packages/view/test/browser/run.ts --engines chromium,firefox,webkit` (an option goes before `--`, as in `-- -t <name>`). After each task: `openspec validate --all --strict --no-interactive`, `bun run format` with `git status` showing only the task's files, the check, and the browser suite when the task touches `packages/view`, `packages/widgets` or `tools/build/`; then tick the box with a `  - Note:` (what was built, the choices made, the evidence) and commit in conventional form, with no AI attribution of any kind. Commit hashes appear only in task text and notes, never in code.

## Scope and order

- **May change:** new files under `packages/contract/src/molecules/`, `packages/contract/src/widgets/items.ts`, `packages/contract/src/fixtures/molecules.ts` and `packages/contract/test/`; the Tree's `tree-props.json`, `checks.ts` and `index.ts` under `packages/contract/src/widgets/tree/` for its PERT props (design decision 8); one appended export block in each of `packages/contract/src/index.ts`, `validate.ts` and `fixtures/index.ts`; `packages/molecules/` (the `wbs-pert` definition, the completed `gantt-plan` file, `index.ts` and their tests; `gantt-widget`'s test-only `test/expand.ts` is removed in 5.2); `packages/core/src/molecules/`, `packages/core/src/ports.ts` and their tests; `packages/server/src/molecule-source/` and its tests; `packages/server/package.json` and its `bun.lock` importer entry, in 5.1 only; `packages/compute/src/board.ts`, the export of the existing `ROUND` from `engine/functions.ts` through `compute`'s index, and their tests; in `packages/view/src/`, the port's `onValuesChange`, the draft store and the question card (design decision 11); `tools/build/shared-modules.ts` and its tests; `packages/widgets/src/graph/` and `src/tree/`; `packages/view/test/browser/wbs.browser.ts`, its fixtures, and `gantt.browser.ts` where F20 changes a scenario; `packages/view/chunk-sizes.json`.
