# Tasks

Each task writes its tests first and sees them fail for the right reason before it implements. "The check" means `bun run build && GITHUB_TOKEN=$(gh auth token) bun run check`. "Coverage" means at least 80% of lines and functions for every file the task adds or changes, from `bun test --coverage`. "Browser files" means the named files run with `bun packages/view/test/browser/run.ts` against the session process at DESIGN's 1,280-pixel floor, in Chromium, Firefox and WebKit, under the browser lock. "The table" of a type is its key table (design decision 2). Requirements cited by name are in this change's delta specs.

Order: group 0, then group 1 (`contract`, at high effort). Then groups 2 and 3 in parallel: group 2 edits only `packages/widgets/src/{kanban,timeline,chart,shared}/`, `ranking/toolbar.tsx` and the widgets' tests; group 3 edits only `packages/view/` (not `chunk-sizes.json`'s `ranking` entry) and `tools/build/shared-modules.ts`. Group 4 (the Ranking) follows groups 2 and 3. Group 5 (skills) follows group 3 and runs in parallel with group 4: it edits only `tools/build/skills*`, `skills/`, `packages/molecules/`, `packages/bench/`, `tools/release/` and their tests. Group 6 follows groups 4 and 5; group 7 is last. Task 4.6 waits for the PO's answer to question 1 and blocks nothing but itself and group 7.
