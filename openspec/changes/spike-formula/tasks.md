Commands run from `openspec/changes/spike-formula/probe/` unless they name the repository root. `bun run.ts <run>` and `bun drive.ts <run>` write `runs/<run>/`, which git ignores; every verdict in `findings.md` names its run. Tasks marked **(needs the PO)** are prepared and left open, with "awaiting PO" in `findings.md`, until the product owner acts. The run is unattended and time-boxed to 13:30 on 2026-10-30 (design, Risks).
