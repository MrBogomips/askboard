# Tasks

Each task writes its tests first and sees them fail for the right reason before it implements. "The check" means `GITHUB_TOKEN=$(gh auth token) bun run check` (it includes `check:skills`). `skills/askboard/` is regenerated with `bun run build:skills`, never edited by hand. "Validate" means `npx --yes @fission-ai/openspec@1.15.0 validate --all --strict --no-interactive`. After each task: `bun run format` with `git status` showing only the task's files, the check, validate; tick the box with a note of about five lines and commit in conventional form, one commit per task.

Order: groups 0, 1 and 2 in sequence; no group runs in parallel. The change has no contract version to bind.
