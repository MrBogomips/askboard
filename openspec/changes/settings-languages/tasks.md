# Tasks

Each task writes its tests first and sees them fail for the right reason before it implements (the repository's TDD rule), with `bun test` at 80% coverage per file. "The check" means `GITHUB_TOKEN=$(gh auth token) bun run check`; "the browser suite" means `bun packages/view/test/browser/run.ts --engines chromium,firefox,webkit` (an option goes before `--`, as in `-- -t <name>`), and "the e2e run" means `bun run test:e2e`. After each task: `openspec validate --all --strict --no-interactive`, `bun run format` with `git status` showing only the task's files, the check, and the browser suite when the task touches `packages/view`, `packages/widgets` or `tools/build/`; then tick the box with a `  - Note:` (what was built, the choices made, the evidence) and commit in conventional form with no attribution. Ticks go in separate `docs(settings-languages): ...` commits, after each code commit.

## Scope and order

- **May change:** new files under `packages/contract/src/schemas/configuration/`, `packages/contract/src/locale/`, `packages/contract/src/fixtures/` and `packages/contract/test/`; one appended export block in each of `packages/contract/src/index.ts`, `validate.ts` and `fixtures/index.ts`, appended entries in `sets.ts` and `BOARD_PROTOCOL_MESSAGES`, the two `enum`s of `schemas/input/ask.json`, the board document's root schema, the three version constants and `requests.ts`' `expected` text (design decision 2); `packages/core/src/config/` and the appended `config?` member of `CorePorts`, with the two calls in the core's ask creation (design decisions 3, 7, 13); `packages/server/src/config-files.ts`, `session-process.ts`, `board-host/boards.ts` and `board-host/local-api/routes.ts` (design, Merge points); `packages/hooks/src/asking-rules.ts`; `packages/view/src/` and `packages/view/test/browser/`; `packages/widgets/src/shared/number.ts`, `packages/widgets/src/gantt/model/date.ts` and the widget host's context; `tools/build/tokens.ts`; `packages/view/chunk-sizes.json`; `packages/server/test/conformance/`.
- **Never changes:** another change's schema files beyond the appended entries above; any `package.json`, `tsconfig*.json` or `bun.lock` (no dependency is added); `packages/compute`; `.github/`; `docs/` before group 11 (changes are drafted in `spine-update-draft.md` and `ux-update-draft.md`); another change's folder under `openspec/changes/`; `.claude/commands/opsx/` and `.claude/skills/openspec-*`; any other worktree.
- **Order:** the contract (groups 1 and 2) before `ask-core` (group 3) and the session process (group 4), which the board host (5) and the hooks (6) need; the strings and formats in the view (7) before the panel and toggles (8) and the widgets (9); the end-to-end scenario, the CI runs and the security review (10) last, then the records (11). Tasks that need E5, E7, `tree-widget` or `gantt-widget` say so, with their form when that change is not on `main` yet (design decision 1).
