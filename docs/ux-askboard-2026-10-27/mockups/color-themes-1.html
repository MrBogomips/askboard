AskBoard colour themes and fonts · round 1

Five sober, technical palettes for the AXFX family identity, each in light and dark, on the golden case ("Is the checkout flow correct as drawn?"). They differ in register: neutral temperature, accent character and contrast level. Variation 1 is golden-1-base with its two known faults fixed. Pick a palette, mix parts, or reject all; the token roles stay the same whichever you choose.

How the tokens are layered (swap the palette without touching components)

1 · PrimitivesRaw hex scales (e.g. Atlassian blue.700 #0c66e4). Listed per variation in the <style> comments with the variables that use each value.
2 · Semantic rolesWhat a colour is for: page, sunken, accent, user change, agent working, ask answered… (the role column). A palette swap re-points roles at other primitives.
3 · CSS variablesshadcn/ui names (--background, --primary, --ring…) plus AskBoard extensions. Components and Tailwind classes read only these.

Role conventions used in every variation. Accent = interactive and selected. Agent hue = the agent's voice (Agent: Working, and the Recommended badge, an alias of it). User-change hue = the user's voice (annotation pins, changed values, highlight), never shared with warning or agent state. Warning = thresholds only (e.g. margin below the agent's minimum). Waiting is neutral everywhere (Ask: Waiting, Agent: Waiting for your answer). Danger = rejected or removed; the Gantt critical path has its own orange token so it never reads as an error.

AskBoard extension variables: --agent --agent-subtle --agent-text --border-strong --change --change-foreground --change-subtle --change-text --critical --destructive-subtle --destructive-text --diff-add --diff-add-mark --diff-del --diff-del-mark --foreground-secondary --gantt-bar --info --info-subtle --info-text --primary-hover --primary-subtle --primary-text --success --success-subtle --success-text --warning --warning-subtle --warning-text --agent-waiting --ask-waiting --ask-partial --ask-answered --ask-closed --ask-discarded --recommended --recommended-subtle.

Aliases (same in every variation): --card-foreground → --foreground, --popover-foreground → --foreground, --secondary → --muted, --secondary-foreground → --foreground, --accent → --muted, --accent-foreground → --foreground, --input → --border-strong, --agent-waiting → --muted-foreground, --ask-waiting → --muted-foreground, --ask-partial → --info, --ask-answered → --success, --ask-closed → --foreground-secondary, --ask-discarded → --destructive, --recommended → --agent-text, --recommended-subtle → --agent-subtle; --radius: 4px. Note that shadcn's --accent is a hover surface, not the brand accent; the brand accent is --primary.

Contrast. WCAG 2 ratios computed from the hex values; a red cell is under 4.5:1 for text or 3:1 for UI marks (lines, dots, rings, bars). Accessibility is best effort: flags are reported, not blocking.

open licences, bundled offline

Fonts are layered like colour: --font-sans and --font-mono (the shadcn/Tailwind theme names) point at a bundled family; swapping a pairing changes those two variables only. The previews load the faces from Google Fonts (the page's only network use); if a card shows a system face, the fonts did not load.
