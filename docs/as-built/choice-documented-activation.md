# As built: `choice-documented-activation`

In code since `choice-documented-activation`: the radio group of `view/src/catalog/fields/` (`roving.ts`: `nextFocus`, moved from `choice/selection.ts`, `radioTabStop` and `radioAt`, which give each radio its attributes, its one Tab stop (the checked radio, else the first) and its handlers; `radios.ts`: `useRadios`, the refs and `radio(index)`), on which the question's single Choice (`choice/single-choice.tsx`) and the single PickField (`pick-field/index.tsx`) are drawn as a `role="radiogroup"` `div` of buttons, the dot a `span` while checked. Manual activation, as the group's own rule: the arrow keys, Home and End wrap and move the focus only, never the draft (so a keyboard pass over the options answers nothing, NFR-10), Space or a click on an unchecked radio selects it, and selecting the selected one changes nothing; the PickField's arrows follow the options its filter shows, and Clear hands focus to the first option. No `style` attribute remains in either, since the Radix root's `outline` is gone. The multiple Choice keeps its roving focus on Radix Checkbox, and the multiple PickField keeps one Tab stop per box with no arrow keys (EXPERIENCE names the exception). `LIBRARY_CHUNKS.radix` no longer lists `RadioGroup`. Chunk sizes that moved (bytes, in `chunk-sizes.json`): `choice` 16,408 to 18,035, `pick-field` 18,020 to 19,000, `radix` 142,757 to 136,929, the shell and nine chunks that import `radix-ui` 14 bytes less each, `timeline` 20 less. No set version moved (input format 1.11, output format 1.10, tool envelopes 1.11, board document 1.10, board protocol 1.7, Snapshot data 1.1 and view manifest 1.1, as on `main`).
