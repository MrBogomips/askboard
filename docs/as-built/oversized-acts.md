# As built: `oversized-acts`

In code since `oversized-acts`: one limit and one measure in `contract/src/message-size.ts` (`BOARD_MESSAGE_MAX_BYTES`, the value `board-host`'s `MESSAGE_MAX_BYTES` now names, `MESSAGE_TOO_BIG_CLOSE` (1009), `utf8Length`, `boardMessageBytes` and `draftRecordChars`), which `board-host`, the board page and the view share. The board page measures each act command before it sends or holds it (`outbox.ts`, `controller.ts`): one over the limit is refused with nothing sent or held, the board stays live, later commands go, and the reply to the view (`ActReply`, `refused` with its size) lets the card say "Not sent: this answer is too large" with the size and the limit (a Submit says so on each question in it and points to Immediate delivery, through `sendSubmit` in `shell/card-acts.ts`), keeping the user's work (NFR-10). A socket closed with 1009 is a settlement, not a drop: the commands it carried and had not seen acknowledged are settled `refused` with `tooLarge` (`SettledAct`), never resent, and their questions say the board refused the answer (`noticeTooLarge`, run by `settle` before `reconcile`, in `shell/size-notices.ts`, where `createSizeNotices` keeps the lines). A draft record past `DRAFT_RECORD_MAX_CHARS` is mirrored by `fitDraftRecord` (`board-page/draft-fit.ts`) without the work of whole questions, the largest first and only as many as needed, never part of one; the board page keeps the whole record for "Copy my unsent work", the leave-page prompt (also on a tab the board moved from, while its last fit left work out; AD-21) and the unsent-work banners, and the draft reply's `leftOut` names the questions whose card says a reload would lose their work. Four strings in both tables (`send.tooLarge`, `send.tooLargeSubmit`, `send.tooLargeClosed`, `draft.tooLarge`, the Italian texts to review); AD-20 and AD-21 amended in place; the browser file `oversized-acts-session.browser.ts`. Chunk sizes that moved (bytes, in `chunk-sizes.json`): `shell` 181,796 to 187,378, `board-page` 975,818 to 979,038, `row` and `toggle` by 2 each. No set moves: input format 1.12, output format 1.11, tool envelopes 1.12, board document 1.11, board protocol 1.8, Snapshot data 1.1 and view manifest 1.1 all equal `main`'s.
