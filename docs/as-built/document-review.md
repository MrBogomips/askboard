# As built: `document-review`

In code since `document-review`: one registry entry in `contract` and `widgets` (`document-review`, folder `document-review/` in each, appended to `WIDGET_TYPES` after the Table): the props (`markdown`, 1 to `DOCUMENT_REVIEW_MAX_CHARS` = 10,000 code points with no control or bidirectional character but line feeds and tabs, by `isEscapedCodePoint`, the one list of escaped characters; `title`, 1 to 120), the result (`{annotations}`, 1 to 100, each anchored by a `quote` selector, `exact` with up to `QUOTE_CONTEXT_MAX_CHARS` = 200 code points of `prefix` and `suffix`; no result for an untouched review), and the annotation body `{text?, replacement?}` in the output format (`ANNOTATION_REPLACEMENT_MAX_CHARS` = 4,000; an empty replacement suggests deleting the passage), AD-7 amended in place. `anchors.ts` (plain ECMAScript, no regular expression over agent text): `quotePassage` widens the context from 32 code points until the quote occurs once and refuses a blank, over-long (2,000) or repeated passage, `placeQuote` and `placeAnnotations` place a quote only where it occurs once, else `detached` (`missing`, `ambiguous`, `overlaps`). `ask-core` checks shapes, IDs and bounds; only the board, which renders the document, places a quote against the reading text, which one function gives the component and the chunk's `check`, kept per item in a `WeakMap` keyed by the item's props object (so a keystroke places nothing again). The Markdown renderer moved from `catalog/text/` to `view/src/markdown/` and is the library chunk `markdown` (`@askboard/view/markdown`), which the Text and the Document review import, `widgets` importing it as AD-1 and AD-9 now say; `tools/check-imports.ts` follows. The pin, the card and the list live in `widgets/src/shared/annotations/` with their `annotations.` strings and name no widget type, for the later annotating widgets. The component marks passages by classes (a `span` per text node, the pin and a suggested edit's replacement after the passage, never inside the agent's `a`), takes a toolbar and a counter, one Tab stop for the document whose Up, Down, Home and End move between blocks and whose Left and Right move between pins, opens links through the board page, and is read-only in a closed ask, a locked board and Snapshots. An annotation whose quote no longer occurs once is detached, listed with "Delete", and blocks "Answer" through `ComponentFacts.check` (the field check's code `detached`, `FieldCheckFailure` and `fieldCheckMessage` each one member longer). Decision 15's gates: `ComponentFacts.revisionBound` (a result that points into the agent's content of the revision it was made on), read by `readOnlyItemsOf` beside `shape` so the item is read-only while the card shows a revision other than its work's, with `onResultChange` writing nothing for it and the field block skipping it; and the revision the card shows read by every gate and reader of a card: `ShownOf` beside `ReadOnlyOf` (`AnswerContext.shownOf`, `shownOfBoard`, one question's shown revision from `workingQuestion`) for `blockedBy`, `heldWithBlock`, `selectRecommended`, `answerNeedsReason`, `heldMissingReason`, `hasRecommendation` and `withEntries`, `idsOver` (the union of the shown and the current items) wherever work is compared, mirrored or cleared, and `shownDocumentOf` (the board document with each question at its shown revision, the same object while none differs) under the board content, the answered results, the compute graph and the ready tracker, so an item only the kept revision holds renders and reports ready, and one only the current revision holds is not awaited (#92, #93, #100); a reload gives the current question, so work held only on a removed item is not restored. An item that fails in the view stops every act of its question at the board page, the one choice to reload excepted, and Submit sends the other questions (#103).
