# As built: `askboard-skills`

In code since `askboard-skills` (#43, merged and archived): the teaching data beside what it teaches (`ASKING_RULE_TEXTS` in `contract`, `WidgetType.skill` in each registry entry, `skill.json` and `MOLECULE_SKILLS` in `molecules`); the generator and its check in `tools/build/skills/` (`bun run build:skills`, `bun run check:skills`, which `bun run check` runs and which also enforces the token budgets), which write `skills/askboard/` (`SKILL.md` and its `references/`); the examples of the shipped files validated by `packages/server/test/skills-examples.test.ts`; and the AskBoard arm of the benchmark loading the `Skill` tool, allowed only as `Skill(askboard:askboard)`, with Claude Code's bundled skills switched off in every arm (`toolsOf`, `buildLaunch`; decision 9). The plugin manifest names no skill: Claude Code finds `skills/` by itself. A change that adds a widget or a molecule gives its teaching data (`skill` for a type, `skill.json` for a molecule), runs `bun run build:skills` and commits `skills/askboard/`. The item catalogue `references/items.md` (`tools/build/skills/catalogue.ts`) holds each type's use, and `SKILL.md` links each reference by name.
