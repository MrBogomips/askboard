# As built: `push-delivery`

In code since E4 (`push-delivery`): `contract`'s E4 block (standalone schemas for the local API, the session file, the push message, the closed event and the board's presence, origin and agent messages, compiled on first call; the session folder's paths; the constants), `core`'s owners and origins, `received` from pushes and stop blocks, the version gate, the agent status and the notices (`src/push/`), `board-host`'s local API on a Unix socket and the session file (`src/board-host/local-api/`), the system notification, `hooks` (`askboard hook <event>` and the local API client, `askboard client <path> [<body>]`, both run by `dist/askboard.mjs`), `mod` (built into `hooks/askboard-mod.js`), and `hooks/hooks.json` with the four hooks and the mod as the hooks module. The session folder is `$XDG_RUNTIME_DIR/askboard`, else `${TMPDIR:-/tmp}/askboard-<uid>`; the session file is named by the Claude Code PID (AD-5).
