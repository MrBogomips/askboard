# As built: `chart-widget`

In code since `chart-widget`: one registry entry in `contract` and `widgets` (`chart`, folder `chart/` in each), after the Timeline in `WIDGET_TYPES`: its props (kind `bar`, `line` or `pie`; at most 100 categories and 5 series, a pie one series of at most 5 slices; `highlights` `many`, `one` or `none`; `unit`; values of at most 1e15 in magnitude or null), its result (`points`, each `{series, category}`, at most 500, each naming a series and a category the revision holds with a value; no result for an untouched Chart, and none at all with `highlights: "none"`), checks, wording, `skill` text and example, so `skills/askboard/` teaches it. In `widgets`, pure modules (`text`, `model`, `layout`, `option`, `reading`, `theme`) and the component, which draws on ECharts' canvas renderer through `echarts/core` with seven modules (bar, line, pie, grid, tooltip, legend, canvas), pinned at `echarts` 6.1.0 with `zrender` 6.1.0 and `tslib` 2.3.0; a guard reads the installed `zrender` source for the rich-text rule agent text must not match, and agent text reaches the canvas only through `chartText`, which escapes controls and puts U+2060 after each `{` that could open a style and before every string, so no label can be an inherited name in zrender's width cache. The tooltip is the canvas's rich-text tooltip (a formatter function, never a template string), drawn in the library's 12px sans-serif. The chart is one Tab stop: arrow keys, Home and End move between points, Space or Enter highlights, a polite live region reads each point, and a counter under the plot counts the highlights. In `view`: the port's `useTheme` (the page root's `.dark` class, one observer for all listeners), so a canvas rebuilds on a theme switch, and the palette tokens `chart-1` to `chart-5` (light and dark) in `DESIGN.md`; the `chart` component chunk (inlined into a board or Snapshot only when it holds a Chart, with the notices of echarts' Apache-2.0 licence and NOTICE, d3's BSD-3-Clause, zrender and tslib); a held Chart result is kept or dropped whole across a revision. Versions: input format 1.8, output format 1.8, tool envelopes 1.8 and board document 1.7, bound on 2026-11-07 on main f2dfb6f3, each one minor past `main`'s (the board protocol 1.6, the Snapshot data 1.1 and the view manifest 1.1 are unchanged).
