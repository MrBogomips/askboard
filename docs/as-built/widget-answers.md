# As built: `widget-answers`

In code since `widget-answers`: the widget sets in `contract` (input format 1.4, output 1.3, tool envelopes 1.4, board document 1.4, board protocol 1.5: Tree, Gantt and molecule-reference items in a question's `items`, the `answer` act's `values` and `derived`, the `formula` warning, an answer event's `tooLarge`, the widget wordings of request problems) with the approved UJ-2 ask and answer as fixtures; in `core`, the send-time expansion of molecule references through the `MoleculeSource` port (one expansion map per ask), AD-13's graph check, the widget answer check, the full edited value kept apart from the log (`AskCore.keptAnswerValues`), `changes` computed once per answer and `tooLarge` answers, and widget fetches; in `mcp-tools` and the session process, `ask` and `update` results with the graph's warnings and `fetch` of a question, a widget item, a reference or an expanded ID; and in `view` and the board page, widget answers sent, shown read-only after the logged answer with their receipt, restored after a reload, with the agent-change notice naming the widgets the agent changed. An answer carries the derived values of every computing item of its question, never alone. An agent asks widget and molecule questions by pull; `ask` and `update` refuse any other widget type, naming it. The `widgets`, `molecules`, `compute` and `bench` packages hold the Tree, Gantt, molecule definitions, formula engine and benchmark.
