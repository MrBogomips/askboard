# Chart

Item type `chart`. It is for a bar, line or pie chart the user reads and may highlight points on.

## With the mouse

Click a bar, point or slice to highlight it and click it again to clear it; hover to read its value.

## What the agent receives

The agent receives the points you highlighted. A chart you did not touch gives no answer.

## Keys

The board shows no keys panel for the Chart yet, and the user's key changes do not reach it: these are its default keys.

| Action | Where | Keys (macOS) |
|---|---|---|
| Go up | plot | ↑ (↑) |
| Go down | plot | ↓ (↓) |
| Go left | plot | ← (←) |
| Go right | plot | → (→) |
| Go to the first | plot | Home (Home) |
| Go to the last | plot | End (End) |
| Highlight the point | plot | Space and Enter (Space and ↩) |
