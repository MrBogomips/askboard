# Document review

Item type `document-review`. It is for a Markdown document the user comments on and suggests edits to.

## With the mouse

Select a passage of the document and press Comment or Suggest edit; click a pin to read, edit or delete its note.

## What the agent receives

The agent receives each comment and suggested edit with the passage it is about.

It has no keys of its own beyond the standard ones in `SKILL.md`.
