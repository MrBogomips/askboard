# PickField

Item type `pick-field`. It is for one or several options picked from a list, as in a form.

## With the mouse

Click an option to pick it, or several where the question allows more than one; a long list has a box to filter the options.

## What the agent receives

The agent receives the option or options you picked.

It has no keys of its own beyond the standard ones in `SKILL.md`.
