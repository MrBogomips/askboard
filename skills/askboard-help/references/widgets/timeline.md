# Timeline

Item type `timeline`. It is for milestones and date ranges the user moves in time and across lanes, as in a roadmap.

## With the mouse

Drag an entry along the time axis or into another lane (Escape cancels the drag), or make it current and use Move earlier, Move later or Move to lane….

## What the agent receives

The agent receives the dates and lanes you changed, entry by entry.

## Keys

The board shows no keys panel for the Timeline yet, and the user's key changes do not reach it: these are its default keys.

| Action | Where | Keys (macOS) |
|---|---|---|
| Go up | entries | ↑ (↑) |
| Go down | entries | ↓ (↓) |
| Go to the first | entries | Home (Home) |
| Go to the last | entries | End (End) |
| Previous tool | toolbar | ← (←) |
| Next tool | toolbar | → (→) |
| First tool | toolbar | Home (Home) |
