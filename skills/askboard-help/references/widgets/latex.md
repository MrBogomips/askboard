# LaTeX

Item type `latex`. It is for one mathematical expression in LaTeX that the user reads and corrects, with a live preview.

## With the mouse

Type or correct the LaTeX in the source box; the preview beside it redraws as you write.

## What the agent receives

The agent receives the whole expression as you wrote it, even if it does not draw.

It has no keys of its own beyond the standard ones in `SKILL.md`.
