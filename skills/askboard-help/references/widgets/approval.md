# Approval

Item type `approval`. It is for a decision on its question's content: approve, approve with changes or reject; put it last in the question it approves.

## With the mouse

Press Approve, Approve with changes or Reject. For changes, write the reason in the note that opens.

## What the agent receives

The agent receives your decision, your reason if you gave one, and any changes you made to the question's other items.

It has no keys of its own beyond the standard ones in `SKILL.md`.
