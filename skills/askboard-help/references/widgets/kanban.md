# Kanban

Item type `kanban`. It is for cards the user moves between 2 to 12 columns, such as statuses, priorities or owners.

## With the mouse

Drag a card to another column (Escape cancels the drag), or make a card current and use Move to… to pick its column.

## What the agent receives

The agent receives the cards you moved and the column each one is in now; their order and the columns stay as they were.

## Keys

These are the default keys. The board's keys panel (the Keys button, or `?`) shows the keys in effect, which the user may have changed in the user configuration file.

| Go down | board | ↓ (↓) |

| Previous tool | toolbar | ← (←) |
| Next tool | toolbar | → (→) |
| First tool | toolbar | Home (Home) |
