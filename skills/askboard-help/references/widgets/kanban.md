# Kanban

Item type `kanban`. It is for cards the user moves between 2 to 12 columns and orders within them, such as statuses, priorities or owners.

## With the mouse

Drag a card within its column or to another column (Escape cancels), or make it current and use Move up, Move down, To top, To bottom or Move to….

## What the agent receives

The agent receives the cards you moved, the column each is in now and, where you reordered a column, their order in it.

## Keys

The board shows no keys panel for the Kanban yet, and the user's key changes do not reach it: these are its default keys.
